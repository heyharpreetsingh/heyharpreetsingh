HOW TO ADD YOUR RESUME PDF
============================

This folder is for static files that will be copied to the build.

To add your resume PDF for download:

1. Place your resume PDF file here and name it: resume.pdf
2. It will be available at: /resume.pdf on your site
3. You can link to it in your code as needed

Note: The current portfolio uses the Print button to generate PDF on-the-fly,
so a separate PDF file is optional.

If you want to offer a downloadable PDF:
- Add your resume.pdf file here
- Update personalInfo.resumeUrl in src/data/portfolio.ts
- Users can download via that link
